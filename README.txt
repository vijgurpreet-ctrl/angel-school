HOW TO RUN
1. Open the folder.
2. Double-click index.html.
3. The website will open in any modern browser.

HOW TO HOST
You may upload the entire folder to GitHub Pages, Netlify, Hostinger/cPanel,
or any normal static hosting service. Keep the folder structure unchanged.

MAIN FILES
- index.html     : Website content
- styles.css     : 3D styling, responsive layout, animations
- script.js      : slider, mobile menu, gallery lightbox, animations
- assets/images  : school photographs and logo
- assets/videos  : school videos

To change any school text, edit index.html in Notepad, VS Code or any HTML editor.
